# 承艺 · 山河入坊（非遗后台整合版）

非遗数字手作「承艺」的可点击原型，用来评审交互框架、产品范围和视觉方向。

本地整合版入口：`http://127.0.0.1:8010/chengyi/`。启动、数据交接和代码位置详见 [整合交接说明](整合交接说明.md)。本次修改在本地分支，没有更新上游在线演示。

**上游在线体验**：https://zeroonehub.github.io/chengyi/ （上游推送到 `main` 分支后，GitHub Pages 自动更新）

- **功能**：以 demo 原型为准，补充了 PRD 里的册页抽屉。
- **AI**：承艺之声接入 FastAPI、Dify Agent、非遗知识库和硅基流动语音。陶艺指令先给建议，确认后修改实际模型；支持按住说话、流式朗读和停止。没有模型配置时提供规则演示。
- **视觉**：第三版。不再沿用 demo 的深绿描金界面，改为「素纸 · 天光」。

## 视觉方向

**原则：器物是主角，界面退到边上。**

- **界面**：宣纸般的暖白底，墨色文字，朱砂只用在品牌印和极少数强调处。标题用宋体，正文用系统黑体。不用描边面板、发光圆点、毛笔字。
- **一屏只露出眼下要用的东西**：创作台每道工序只显示两样工具；承艺之声收在右下角，需要时再展开；旁白只出现几秒就淡去。
- **山河**：一幅会动的绢本青绿山水。设色取《千里江山图》：赭石打底、石绿铺陈、石青压峰，山石用墨线皴出轮廓；天和云都是绢的本色留白，远山淡进绢里。地名像地图注记：一点、一线、一个名字。
- **器物**：按实物摄影来渲染。场景是一面无缝背景纸和一扇窗光，有柔和的影子、釉面反光和手工痕迹：
  - 瓷器：有壁厚和圆润的口沿，圈足露胎，足边泛火石红。釉在下腹积厚、在口沿变薄（出筋）。青瓷带开片。月白釉配青花，其他釉色配刻花。拉坯时湿泥坯在陶车上转，能看到旋纹。施釉后是发灰、粉涩的生釉。从施釉进入烧成时，会有一段入窑升温、出窑冷却的过程。
  - 剪纸：程序生成传统纹样，包括锯齿纹、月牙纹和团花。前两道工序看到的是折叠成一角的多层纸，剪口落在这一角上；展开后纸上留有折痕，剪口在背景纸上投下影子。暖金纸是有金属光泽的箔纸。
- **作品照片**：「我的作品」、产地样品、命名与分享浮层、下载的图片，都用同一个摄影棚离屏「拍」出来。照片里的就是工坊里做的那件。

所有界面颜色、字体、动效时长都集中在 `css/tokens.css`。山水设色在 `js/render/landscape.js` 的 `PALETTE` 里。釉色与纸色在 `js/render/textures.js` 的 `GLAZES` 和 `PAPERS` 里。

## 怎么打开

- **带 AI 的整合版**：需要 Python 3.12 或更新版本。Mac 双击 `启动承艺.command`，Windows 双击 `启动承艺-Windows.bat`。首次启动会安装依赖并初始化独立配置，前后端一起运行在8010端口；端口被占用时选择附近空闲端口。浏览器打开 `/chengyi/`，后台设置在 `/admin`。Dify和硅基流动密钥在本机配置；没有密钥时使用演示模式。请保留启动窗口。
- **只看原型**：双击 `start.command`。会弹出一个终端窗口，浏览器随后自动打开原型；承艺之声用规则演示。关掉这个终端窗口，服务就停止了。

第一次双击时，macOS 可能提示「无法验证开发者」。这时在 `start.command` 上点右键 →「打开」，确认一次即可。

注意：直接双击 `index.html` 打不开。浏览器不允许本地文件加载 JS 模块，必须通过本地服务访问。

**运行要求**：需要支持 WebGL 2 的浏览器，推荐最新版 Chrome、Edge 或 Safari。集成显卡也能跑；如果感觉卡，可以在「设置」里选「减少动态」。不支持 WebGL 时，器物会退回成平面示意图。

## 场景与交互清单

| 场景 | 可以操作的内容 |
| --- | --- |
| 开场 | 画面从纸白中显影，出现题名「山河寻艺」。点「启程」后镜头落到山河总览。可以跳过，可以重播，有声音开关 |
| 山河寻艺 | 三级：总览 → 产地聚焦 → 工坊入口。点地名后镜头飞往该地，右侧出现产地卡：一张样品照片，加几行字。按住照片，它会从朦胧变清晰；也可以点「直接看」。拖动平移、滚轮远近、点空白收起。左上可以按地区查找，或继续上次的作品 |
| 工坊入口 | 作品在摄影棚里，左侧是一段介绍和三个选择：「开始创作」「看工序」「认识工具」。说明从右侧滑出 |
| 创作台 | 顶部是三道工序（壹、贰、叁），可以随时跳转。底部工具盘只放当前工序的工具：瓷器是「器型 + 宽窄 → 釉色 + 纹样 → 完成」，剪纸是「纸形 + 纸色 → 纹样 + 繁简 → 完成」。器物可以拖动旋转、滚轮远近。支持撤销、重做，「重置」需要二次确认。改动自动保存在本机 |
| 承艺之声 | 右下角打开对话。知识讲解按当前场景流式显示并附检索文档名；瓷器造型指令交给后台规划，确认后渲染实际轮廓并回传执行结果。支持爱心、三角形、局部修改、材质、转盘、视角和工程导出。剪纸保留原有规则修改。支持按住说话和朗读回复，停止按钮终止当前请求与声音。后台不可用时退回规则演示；设置中可模拟AI不可用 |
| 册页 | 任何场景都能打开，对话里的出处链接会直接定位到对应段落 |
| 完成与作品 | 完成作品后先命名，再「落款收藏」，作品进入「我的作品」。每件作品都是一张照片，可以继续创作、分享（下载图片、复制介绍）、导出实物制作需求单，也可以删除。没有作品时，页面给出两个起点：瓷瓶和红纸 |
| 设置 | 声音（默认关）、动态效果（完整 / 减少）、模拟 AI 不可用、重播开场、重置演示数据、原型说明 |

## 模拟边界

- **AI**：整合版通过同一个服务访问页面与后台，默认使用当前页面的地址。单独的静态5173原型仍可连接原后台8000；上游GitHub Pages没有部署本次服务。持续实时通话尚未实现，目前为按住说话。模型响应和语音起播仍受供应商耗时影响。
- **账号与存储**：免登录，作品只存在浏览器的 localStorage 里。接入账号和云端时，替换 `js/core/store.js` 即可。
- **三维**：器物、纸张、陶车、摄影棚和山水全部由程序实时生成，没有任何图片或模型文件。要做到真正的照片级，后续可以替换成扫描模型和实拍材质，接口不用变（见 `js/render/craftmesh.js`）。
- **内容**：地区、非遗项目名称、册页文案都是示例，界面上标了「示例 · 待核实」，上线前需要内容组逐条核验出处和素材授权。
- **不做的功能**：公开分享链接、真实下单与付款、商家审核。

## 常见改动

- **换配色和字体**：改 `css/tokens.css`。山水设色改 `landscape.js` 的 `PALETTE`。
- **调釉色、纸色**：改 `textures.js` 的 `GLAZES`（烧成色、积釉色、出筋色、生釉色、纹样画法）和 `PAPERS`。界面上的色块颜色在 `js/data/crafts.js`。
- **改器型**：改 `craftmesh.js` 的 `OUTER`（外轮廓）和 `BANDS`（纹饰带位置）。
- **调光**：改 `studio.js` 里的主光 `key` 和反射环境 `makeEnvironment`。
- **调镜头**：在 `landscape.js` 的 `PRESETS` 里调开场、总览、聚焦三个机位。
- **新增可创作品类**：在 `crafts.js` 里加品类配置，在 `album.js` 里补册页内容，在 `craftmesh.js` 里补造型与材质。
- **新增地点**：在 `js/data/regions.js` 的 `SAMPLES` 里加一条，用百分比表示在图幅上的大致方位。在 `SAMPLE_STATES` 里可以指定样品照片的样子。

## 测试

整合服务启动后，在浏览器打开 `http://localhost:8010/chengyi/tests/smoke.html`。页面会自动走一遍主流程，最后在页面上列出每项结果。新增检查在 `/chengyi/tests/integration.html`，检查实际轮廓、确认、手动编辑、撤销重做、旧建议拦截和导出。

本次在浏览器实测原流程45/45、新增整合流程11/11通过。原流程用 `?ai=off` 检查规则版，另外7项模拟大模型后台；新增整合检查连接实际本机后台。

`tests/ai-live.html` 需要讲解后台在运行。它要按真实时间等后台生成，不能用 `--virtual-time-budget` 跑（虚拟时间会让前端的 60 秒超时提前触发）；在普通浏览器里打开即可。
