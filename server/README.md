# 非遗大模型讲解后端 · 轻量版

后台已接入 Dify 的“非遗讲解人”旧版 Agent，支持知识库问答、部位讲解、分句播报和短录音转写。

## 现在可以打开

- 管理后台：http://127.0.0.1:8000/
- 文字体验：http://127.0.0.1:8000/demo
- 语音体验：http://127.0.0.1:8000/voice
- 陶艺工作台：http://127.0.0.1:8000/workbench/
- 前端接口文档：http://127.0.0.1:8000/docs

管理员账号在项目目录的 `.local-credentials.txt`，Dify 与硅基流动密钥保存在后端 `.env`，这些文件不要交给前端或上传到公共仓库。

当前已有“青花缠枝莲纹碗”（C001）与碗心、外壁两个部位入口，详细事实从 Dify 非遗知识库检索。其他三件物品仍是演示资料。

## 使用

服务未运行时，双击 `启动后台.command`。已经运行时直接打开页面，不要重复启动占用同一个端口。

本次后台使用独立进程运行，关闭或中断聊天不会停止服务。独立启动入口为 `scripts/run_local_background.py`，日志位于 `data/backend.log`，进程编号位于 `data/backend.pid`。

管理页面可选择 Dify、保存应用 Key、测试连接；声音设置支持 Anna、Bella、Alex、Benjamin、Charles、David 六种音色。开发环境保存设置立即生效。

语音页面可以选择物品、点击部位、打字提问，也可以按住按钮说话后松开发送。首次使用需要用户允许麦克风。录音期间暂停声音，避免把讲解录进去；单次不超过 30 秒。

“暂停讲解”“继续播放”“再讲一遍”“停止讲解”等明确语音指令由页面执行播放控制，普通问题交给 Agent。声音使用 PCM 流边到边播，并显示第一段文字、首批声音到达与起播耗时；首段提前切分，避免等完整长句。

测试页也支持输入或说出“打开青花缠枝莲纹碗”“看看碗心”“看看外壁”：先切换展品或选中部位，再经后台确认执行结果，随后触发对应讲解。重名或未知目标会提示选择。首版通过常见指令句式和已发布目录匹配目标，不能理解的操作不会擅自跳转。

## 安装到另一台电脑

需要 Python 3.12 或更新版本。不要复制本机 `.venv`：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/bootstrap.py
.venv/bin/python -m alembic upgrade head
.venv/bin/python -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

安装后填写自己的 Dify 应用 Key 和硅基流动 Key，并录入与知识库名称对应的物品。当前本机的 C001 资料关联不会自动出现在新数据库中。

```sh
.venv/bin/python -m pytest -q
.venv/bin/python -m alembic check
```

## 验证与边界

2026-10-15：69 项 Python 测试和 4 项客户端控制器检查通过；真实 Dify 知识库回答、硅基流动播报、录音文件转写及浏览器声音播放通过。浏览器实际开始播放约 7.25 秒，比第一段文字晚约 0.76 秒；这是一次短问答实测，不是固定速度承诺。

麦克风权限、实际按住录音操作及不同手机浏览器需人工试用。识别结果可能包含错字，不能凭一次转写成功认定准确率已达标。正式前端动画、真实 MySQL/PostgreSQL 数据库和服务器部署仍需联调。

前端调用自己的后台接口，不直接持有供应商 Key。详见 `docs/前端对接说明.md`、`docs/部署与模型配置.md`、`docs/语音交互需求.md` 和 `docs/验收记录.md`。

自然语言控制界面接口、前后端分工、回执与参考客户端，见 [Agent 界面交互约定](docs/Agent界面交互约定.md)。后台与参考页已实现；正式前端仍需绑定实际画面、模型和动画，可用接口以 `/docs` 为准。

2026-10-18：用户提供的陶物 3D 工作台已接到本机后台。保留原有鼠标与手势功能，增加文字指令、按住说话、执行反馈和语音回复。尺寸等明确指令直接处理，组合器形需求交给同一个 Dify Agent 返回受约束的工具参数，再修改实际 Three.js 模型。14 个工具覆盖器形、尺寸、局部轮廓、釉色、转盘、视角、历史和保存导出。

工作台接入说明、接口与实际限制见 [陶艺工作台接入](docs/陶艺工作台接入.md)。目前使用按住说话后转写，尚未实现持续实时语音；一次 2.68 秒的合成测试录音转写耗时约 8.88 秒。实际麦克风录音与不同浏览器仍需试用。

工作台造型已扩展：爱心、三角形、方形、椭圆、星形、花瓣、水滴和自定义俯视轮廓可以用于整个器物或指定部位。支持按瓶口、瓶颈、瓶肩、肚子、底部调整，并能只改前后左右的一侧。“再收一点”会承接上一次修改的位置；一条指令中的多项修改合并为一次撤销。

## 临时网址分享

双击 `开启临时分享.command`，生成的网址会保存在 `临时工作台网址.txt`，把完整网址发给对方即可。电脑需要保持开机、联网；AI 和语音请求使用本机后台已有配置及其额度。

访问者通过专用链接进入工作台，管理页面、密钥配置和其他后台页面不对外提供。分享入口通过 HTTPS 访问，声音事件保持流式传输。连接断开后重新开启分享，网址可能改变；邀请入口最长保留 24 小时。

双击 `停止临时分享.command` 可以关闭外部访问，本机后台继续运行。分享进程与日志在 `data/temp-share-*`，不要把这些文件连同项目转发。

临时通道使用 [localhost.run](https://localhost.run/docs/http-tunnels/)，适合短期演示。它没有本项目的长期服务承诺；正式交付仍需部署到服务器。

## 发给别人

运行 `.venv/bin/python scripts/make_share.py`，在 `分享文件/` 生成 `非遗陶艺工作台-分享版-日期.zip`。压缩包只收录代码、说明和启动文件，不含 `.env`、`后台账号.txt`、数据库、录音和个人数据。对方解压后双击启动文件，第一次启动需要联网安装，电脑上要先有 Python 3.12 或更新版本。
